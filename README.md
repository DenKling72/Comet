# 🚀 Звёздная Академия (Star Academy)

Образовательное игровое PWA-приложение для тестирования школьника (9 лет).
Ребёнок проходит квесты вместе с персонажами — Капитаном Кометой, Робо-Байтом
и инопланетянином Зорпом — зарабатывает «Звёздную пыль» и улучшает корабль.

## Стек
- **Backend:** C# / ASP.NET Core Web API
- **БД:** PostgreSQL 16 + Entity Framework Core (Npgsql)
- **Frontend:** HTML / CSS / Vanilla JavaScript (ES6+), PWA
- **Принцип:** новые предметы, темы и типы вопросов добавляются ДАННЫМИ, а не кодом
  (специфика хранится в `jsonb`).
